# Security Policy

## Supported Versions

O projeto ARES encontra-se atualmente em desenvolvimento ativo. As atualizações de segurança são aplicadas exclusivamente à versão mais recente na ramificação (branch) principal (`main`).

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

A segurança é uma prioridade na arquitetura do ARES. Se detetar alguma vulnerabilidade no código, na captura de tráfego ou na gestão de estado, por favor reporte-a de forma privada antes de abrir uma *Issue* pública.

1. Navegue até ao separador **Security** no repositório.
2. Clique em **Advisories** e selecione **Report a vulnerability**.
3. Forneça uma descrição detalhada da anomalia e, se possível, os passos para a reproduzir.

Pode esperar uma resposta e análise inicial num prazo de 48 horas. A correção será priorizada na esteira após a validação.
